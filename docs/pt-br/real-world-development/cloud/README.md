O **[agente de nuvem do GitHub Copilot](https://docs.github.com/copilot/concepts/agents/cloud-agent/about-cloud-agent)** permite que o GitHub Copilot trabalhe de forma assíncrona na nuvem. Você atribui uma tarefa no GitHub e o agente explora o repositório, faz alterações e abre uma pull request em segundo plano, enquanto você continua com outras atividades.

Nestes exercícios, você adicionará instruções personalizadas para o agente de nuvem e atribuirá uma issue do GitHub para ele implementar. Você revisará e usará agentes personalizados, acompanhará e orientará sessões no painel de agentes e finalizará revisando as pull requests e iterando sobre os resultados.

## Pré-requisitos

Antes de participar deste workshop, verifique se você tem:

- [ ] Uma conta do GitHub com um plano ativo **Copilot Student, Pro, Pro+, Business ou Enterprise**
- [ ] O agente de nuvem do Copilot habilitado para sua conta ou organização

> [!TIP]
> Estudantes verificados podem obter o GitHub Copilot gratuitamente pelo [GitHub Education][callout-student-plan-education]. O plano **Copilot Student** inclui agente, MCP, revisão de código e Copilot CLI, permitindo concluir todos os ambientes.

[callout-student-plan-education]: https://github.com/education/students

> [!NOTE]
> O agente de nuvem está disponível nos planos **Copilot Student, Pro, Pro+, Business e Enterprise**, mas não no Copilot Free. No Copilot Business ou Enterprise, um administrador precisa habilitá-lo para a organização.

> [!NOTE]
> Este ambiente não aborda MCP. Para usar servidores MCP com o Copilot, consulte o [ambiente CLI](../cli/) ou o [ambiente VS Code](../vscode/).
